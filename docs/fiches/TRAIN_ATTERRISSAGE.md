# Train d'atterrissage

Rôle : absorption du posé et support batterie. Pas d'équivalent aviation
distinct à inventer — nom brut.

| | |
|---|---|
| **Composition matérielle** | Quatre jambes avec patins caoutchouc, imprimées en **PLA** (comme le reste des pièces imprimées 3D du drone — coque, supports). Fixées au châssis par 4 vis traversantes + inserts filetés. |
| **Interface logicielle** | Aucune — pièce purement mécanique, pas de capteur associé. |
| **État actuel** | Fabriqué et monté (hardware terminé). |
| **Redondance / sécurité** | N/A. **Double rôle notable** : sert aussi de support batterie — la batterie est montée sur le ventre du drone, portée par le même ensemble que le train d'atterrissage. |
